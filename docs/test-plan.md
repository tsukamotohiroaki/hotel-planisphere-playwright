# テスト計画

- 目的： HOTEL PLANISPHEREの主要機能が仕様どおり動くことを確認し、回帰テストを自動化する

- 範囲（テストしない範囲も含む）：
テストする範囲：ログイン ・ログアウト ・会員登録 ・宿泊プラン算出・宿泊予約・退会
テストしない範囲：操作感や速度などの非機能はテストしない。

- 方針（アプローチ）：自分でテスト計画→分析→設計→テスト自動化までの一連の流れを実施する
- 役割：自分は分析・設計・実装を担当し、AI はレビューと Git・CI 作業を担当する。（AIはベテランQAエンジニアとしてお目付役として、レビューや助言に徹し、基本的に答えは教えないスタンス）

- スケジュール：
テスト計画：10/27
最優先機能の分析：10/28
最優先の機能をテスト設計と自動化対象の選別：10/29
自動テストを実装（1周完走✅）：10/30
2つ目の機能に着手：10/31
👆イシューを見直したいです。

- 完了基準：各 Issue の完了条件を参照する（最終的には、設計したテストケースが自動化され、CIで緑になること）

環境・ツール：Playwright / TypeScript、GitHub Actions
